Non-homologous isofunctional enzyme candidates in neurologically relevant helminths

Authors: Leandro de Mattos Pereira, Carlos Graeff-Teixeira and Alessandra Loureiro Morassutti

Status: Database resource / manuscript in preparation

Abstract

This public Databiomics resource organizes AnEnPi-derived comparative enzymology outputs for identifying non-homologous isofunctional enzyme candidates in neurologically relevant helminths, supporting reproducible target prioritization, manuscript preparation and downstream database integration.

Workflow

  1. Curate parasite and host enzyme datasets.
  2. Run comparative non-homology and isofunctionality screens.
  3. Annotate candidates against public resources.
  4. Publish tables, FASTA, figures, database and static pages.
